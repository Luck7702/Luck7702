## ⚡ About Me

I'm a Computer Science student at BINUS University in Tangerang, Indonesia, currently working as a **Cloud Engineer Intern at eCloudvalley**, an AWS Premier Tier Partner. My lane is **Go backend + AWS cloud infrastructure**: I like designing how systems fit together, provisioning them with Terraform, and figuring out why they break.

- ☁️ Cloud Engineer Intern @ eCloudvalley Indonesia — migration PoCs and internal tooling
- 🏗️ Working toward becoming a Cloud / Solutions Architect
- 📜 Next certification target: AWS Solutions Architect – Associate (SAA-C03)
- 🧱 Infrastructure as Code with Terraform, CI/CD with GitHub Actions
